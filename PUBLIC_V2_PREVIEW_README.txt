DEADEND SCENTS — PUBLIC V2 PREVIEW

SAFE PREVIEW INSTALL
1. In your GitHub repository root, create a folder named: preview-v2
2. Upload EVERY file and the assets folder from this package into preview-v2.
3. Do not replace your root index.html, styles.css or app.js yet.
4. Wait for GitHub Pages to deploy.
5. Open: https://deadendscents.com/preview-v2/

This preview is marked noindex/nofollow so search engines should not index the test copy.

WHAT CHANGED
- Explore panel replaces the green hero copy: Discovery Packs, Seasons, Styles, View all fragrances.
- Search remains below Fragrance of the Week.
- Landing catalogue shows up to 8 New/Staff Pick fragrances rather than the full collection.
- View all reveals the full catalogue. Searching/filtering automatically searches the full catalogue.
- Uniform compact fragrance tiles.
- 3 cards across on normal phones; 4 on larger phones; 5 tablet; 6 desktop; 8 wide desktop.
- Fixed image area and reserved inspiration area keep every tile the same height whether inspired or original.
- iPhone search input is 16px to prevent Safari auto-zoom.
- WhatsApp cart link is populated automatically. Messenger button is included; Messenger itself does not support pre-populating arbitrary text through a standard m.me web link, so the order text remains visible/copyable.
- Local catalogue snapshot paints first to improve perceived loading speed.
